Production Deployment Blueprint

PostgreSQL Relational Schema, Auth & External Integrations

This standalone client uses a relational store in localStorage mirroring the exact PostgreSQL schema below. Below is the transparent status of every external integration.

AI Reasoning Model (GPT-6 Luna / Fallback) API Key Needed

Built-in Math.js symbolic solver runs locally with zero keys. Configure OPENAI_API_KEY or GEMINI_API_KEY in Settings to route through external LLMs.

Google OAuth 2.0 & PostgreSQL Backend Env Required

Requires DATABASE_URL (PostgreSQL 16+), GOOGLE_CLIENT_ID, and GOOGLE_CLIENT_SECRET on server routes. Never exposed in frontend code.

Guardian Consent Verification Active Flow

Supports under-18 gating, jurisdiction selection (COPPA / GDPR-K / DPDP), approval token generation, and one-click revocation. Legal compliance requires counsel review before public launch.

Canvas LMS Export QTI XML Export Ready

Generates Canvas-compatible QTI 1.2 XML packages for direct import. Live Canvas REST API push requires institution OAuth tokens.

CREATE TABLE users (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  email TEXT UNIQUE NOT NULL,
  password_hash TEXT,
  google_oauth_sub TEXT UNIQUE,
  birth_year INT NOT NULL,
  is_minor BOOLEAN GENERATED ALWAYS AS ((EXTRACT(YEAR FROM CURRENT_DATE) - birth_year) < 18) STORED,
  education_level TEXT NOT NULL DEFAULT 'engineering',
  curriculum TEXT NOT NULL DEFAULT 'Universal',
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE TABLE guardian_consents (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  guardian_email TEXT NOT NULL,
  jurisdiction TEXT NOT NULL, -- 'US-COPPA', 'EU-GDPR', 'IN-DPDP'
  status TEXT NOT NULL CHECK (status IN ('pending', 'approved', 'revoked')),
  verification_token_hash TEXT NOT NULL,
  verified_at TIMESTAMPTZ,
  revoked_at TIMESTAMPTZ
);

CREATE TABLE sessions (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  title TEXT NOT NULL,
  mode TEXT NOT NULL,
  context_summary TEXT,
  updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
CREATE INDEX idx_sessions_user_updated ON sessions(user_id, updated_at DESC);

CREATE TABLE messages (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  session_id UUID NOT NULL REFERENCES sessions(id) ON DELETE CASCADE,
  role TEXT NOT NULL CHECK (role IN ('user', 'assistant', 'system')),
  content_markdown TEXT NOT NULL,
  verification_status TEXT,
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
